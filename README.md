# 📓Portfólio / Currículo Web

Este projeto é uma página de currículo online feita inteiramente em **HTML5 puro e semântico**.

O objetivo do trabalho foi estruturar e organizar informações profissionais de forma limpa, contendo:
* Cabeçalho com menu de navegação por âncoras.
* Seção "Sobre Mim" com foto de perfil e habilidades.
* Tabela com a lista de projetos desenvolvidos.
* Formulário de contato estruturado com campo de mensagem e assunto.
* Rodapé com dados de contato e direitos autorais.
